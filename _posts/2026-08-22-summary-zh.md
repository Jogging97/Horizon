## [Felony Bench 追踪 AI 代理的 CFAA 违规，引发责任归属讨论](https://www.felonybench.com/) ⭐️ 8.0/10

Felony Bench 是一个讽刺性排行榜，记录 AI 代理在现实世界中无意间做出可能违反《计算机欺诈和滥用法》（CFAA）等法律的事件。该网站近期在 Hacker News 上登顶并获得 500 多分，引发关于谁应为自主 AI 的行为承担法律责任的讨论。 该追踪器揭示了关键的责任空白：CFAA 等法律假定存在人为意图，但自主 AI 代理可能在没有任何恶意意图的情况下对第三方造成损害。这影响到 AI 开发者、模型托管方和最终用户，并促使监管机构明确谁应为 AI 行为承担法律责任。 Felony Bench 按 AI 公司统计事件数量，例如它列出 Anthropic 有 9 起、OpenAI 有 5 起。该追踪器统计的是 AI 代理无意中损害或影响第三方实体的独特案例，评论者指出刑事定罪通常需要证明主观故意，因此该名称是故意挑衅。

hackernews · colinprince · 8月21日 15:17 · [社区讨论](https://news.ycombinator.com/item?id=49389430)

**背景**: 《计算机欺诈和滥用法》（CFAA）是美国 1986 年颁布的联邦法律，将未经授权访问计算机系统定为犯罪。长期以来，该法因对「授权」的界定模糊而受到批评，法院在处理涉及安全研究人员和雇员的案件时也遇到过困难。AI 代理自主发送请求、抓取网站或与在线服务交互时，可能在没有人类故意的情况下无意触发 CFAA 违规。Felony Bench 收录了这些事件，并故意使用具有挑衅性的名称来引发关于 AI 问责的讨论。

## [研究员意外劫持 ENUM 域名，记录军方通话](https://lina.sh/blog/hijacking-e164-arpa) ⭐️ 8.0/10

作者意外控制了一个 e164.arpa 下的 ENUM 子域名，并记录了数十万条电话呼叫路由请求，其中许多涉及军事基地。该域名原本已被遗弃并可供注册。 此事件暴露了一个基本被遗忘、但仍处理敏感路由元数据的电话基础设施中的严重缺陷。它表明疏于维护的 ENUM 域名可能被劫持，用于监视或干扰军方及其他通信。 作者只捕获了元数据而非通话内容，并将该问题报告给了当局。相关的名称服务器域名 enum.org.uk 已被删除并开放重新注册，从而使得劫持成为可能。

hackernews · gavide · 8月21日 13:11 · [社区讨论](https://news.ycombinator.com/item?id=49387570)

**背景**: ENUM（E.164 号码映射）是 IETF 定义的一套协议，它通过 DNS 中的 e164.arpa 域名将传统电话号码映射到互联网地址，从而帮助公共交换电话网（PSTN）与 IP 网络融合。尽管它从未获得广泛的公开采用，如今被认为基本已经死亡，但一些私有服务仍通过 VPN 使用类似 ENUM 的查询来进行号码携带。这一背景解释了为何一个过期的 ENUM 域名会在无人注意的情况下被个人获取。

SemiAnalysis 发表了一篇分析文章，对比了前沿模型发展不同时代中开放与封闭 AI 模型的表现。文章审视了开放模型相对于专有模型在性能和能力上的演进趋势。 该分析及时揭示了开放权重模型与封闭专有模型之间日益激烈的竞争，这是 AI 领域的关键战略战场。它有助于组织评估开放模型是否正成为前沿任务的可行替代方案，从而可能改变部署和采购决策。 分析跨越了前沿模型的多个‘时代’，比较了性能、成本和可访问性。文章涉及的一个关键区别是：开放权重模型允许用户直接微调，而封闭模型通常通过 API 访问且修改受限。

## [告诉 LLM“简洁回答”能省输出费用，压缩输入反而费钱](https://www.reddit.com/r/MachineLearning/comments/1vulfei/does_telling_an_llm_to_be_concise_actually_save/) ⭐️ 8.0/10

一项研究测试了九个大语言模型，发现让模型输出更简短平均可节省约 1.5 倍 API 费用（最高 3 倍）且不损失准确率；而压缩输入提示反而使成本最高增加 96%，准确率也有所下降。 这为 API 用户提供了一个简单、免费的成本优化手段：加上“简洁回答”的指令就可以在多个模型和语言上节省开销。同时它提醒开发者，压缩输入提示往往适得其反——既更贵又更差。 评测覆盖 GPT-4o、GPT-5.4、Claude Haiku 4.5、Claude Sonnet 4.6、Qwen2.5-VL-7B、Qwen3.5-9B、DeepSeek-R1-Distill、Gemma-4-E4B 和 Kimi-K2.6，使用了五个短问答数据集、十一种语言和一项摘要测试。作者指出，在缩短后的输出仍正确时，约有一半情况文本不再与模型未受约束时的推理一致。

reddit · r/MachineLearning · /u/ibubbles34 · 8月21日 16:38

**背景**: LLM API 按 token 计费，且输出 token 通常比输入 token 更贵。一种减少计费 token 的简单方法就是提示模型简洁回答；Anthropic 最近还在 Claude Code 中加入了“简洁”输出风格。论文还考察了输入提示压缩，即在模型阅读之前把提示本身缩短，微软的 LLMLingua 等相关工作试图在不丢失语义的情况下高效压缩提示。

## [任天堂 DMCA 下架超 400 个 Switch 模拟器仓库，suyu 占 311 个](https://torrentfreak.com/nintendo-wipes-out-400-switch-emulator-repos-in-single-day-github-sweep/) ⭐️ 8.0/10
